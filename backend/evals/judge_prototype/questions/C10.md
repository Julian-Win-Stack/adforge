Question C10, staged like real life: is the scene in this clip set up the way this action is really done, the whole clip through?

First state, in one sentence, the action the spoken line needs (what the person does with the product, to what). Then check against it, in this order:
1. Body position: is the person placed the way this action is really done?
2. Which hand: is the product in a hand that can do the action, held the way people really hold it?
3. Which part of the product: is the action set up on the part it is really done with?
4. The target: is it set up on the right thing?
Fail when any of these is the wrong kind (Rule B), at the start or when it breaks during the clip.
Pass when it is the right setup, even if imperfect. "doesnt_apply" when the clip shows no action to stage (a person just talking, or the product alone).
