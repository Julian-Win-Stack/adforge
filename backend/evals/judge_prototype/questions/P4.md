Question P4, staged like real life: is the scene set up the way this action is really done?

First state, in one sentence, the action the spoken line needs (what the person does with the product, to what). Then check against it, in this order:
1. Body position: is the person placed the way this action is really done (for example lying, sitting, standing, which way they face)?
2. Which hand: is the product in a hand that can do the action, held the way people really hold it?
3. Which part of the product: is the action set up on the part of the product it is really done with (the right slot, opening, button, side)?
4. The target: is it set up on the right thing?
Fail when any of these is the wrong kind (Rule B): wrong body position for the action, a hand that can't do it, the wrong part of the product, or the wrong target.
Pass when it is the right setup, even if imperfect. "doesnt_apply" when the picture shows no action (the product alone on a surface, a person just talking with nothing to stage).
